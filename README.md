# Student-Grade-Calculator
A simple Python project to calculate student marks, total, percentage, and grade.
## About the project
student Grade Calculator is a simple Python mini project that calculators a student's total marks percentage and grade based on marks entered for five subjects.

## Features
-Accepts student name
-Takes marks for five subjects
-Calculate percentage
-Displays grade based on percentage

 ## Technologies Used
 -python 3

 ## How to Run 
 1.Install Python 3 on your computer.
 2.Download or clone this repository.
 3.Open a terminal in the project folder.
 4.Run the following command.
    python"Student grade calculator.py"
 5.Enter the student name and marks when prompted.

 ## Grading System
 |---|---|
 |90 and above|A|
 |75 to below 90|B|
 |50 to below 75|C|
 |Below 50|D|

 ## Example
 For marks of 90,85,95,80,and 90:
 -Total 440/500
 -Percentage:88%
